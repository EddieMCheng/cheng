# Progressive Curriculum

Use this sequence when creating teaching documents.

1. Point: one named point, position, color.
2. Line: two points and a connection.
3. Shape: triangle, square, circle, polygon repetition.
4. Group: a named object made from child parts.
5. Transform: move, scale, rotate, orbit.
6. Spread: use `±` to show range, thickness, surface, or variation.
7. Label: use `.name`, font, alignment, and dynamic text.
8. Time: add `time` to make a point or group move. Use `∞1` for cyclic turns (`sec.v=time/1000/60∞1`). Keep that live `v` in G, not F.
9. Touch: use `Mx`, `My`, `touch`, `drag`, or `click`.
10. Memory: preserve previous values or authored state in `D`/`E`.
11. Simulation: express a rule such as gravity, orbit, or growth.
12. Interface: make controls using the same objects being controlled.
13. Explanation: create a document that teaches its own notation.
14. Self-editing: expose document manipulation through in-language UI.

Prefer one new idea per beginner document. Later documents can combine several layers, but each layer should still be visible in the text.
